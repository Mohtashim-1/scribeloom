Default UI: toolbar, bubble menu, slash menu, link editor, and table and image controls in `@openedit/ui`; tables, images and the slash menu in `@openedit/extensions`; light and dark theme tokens in `@openedit/themes`. `@openedit/react` gains UI slots, themes and `useEditorContext()`. `basics` gains highlight, text alignment and task lists.
