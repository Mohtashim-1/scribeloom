# 8. AI: one streaming method, previews as decorations

Date: 2026-10-12
Status: accepted

## Decision

- **A provider is one method**, `stream({ system, prompt, signal })`, yielding
  text. Anything can implement it. The shipped adapter speaks the OpenAI chat
  completions protocol, which Ollama, LM Studio, vLLM and others share. With
  no `model` set it uses the first one the endpoint lists, so a local server
  works with only a URL.
- **The result is previewed as a decoration**, not inserted. The document,
  its undo history and any collaborators are untouched until the user
  accepts. The text being worked on is tracked through document changes.
- **Accepted text is inserted as plain text.** Model output is never parsed
  as HTML or Markdown.
- **No request is made** unless a provider is configured and the user runs an
  action. There is no telemetry.

## Trade-offs

- An API key passed to the adapter is visible in the browser. The docs steer
  hosted use towards a proxy.
- Formatting in the selection is lost when a rewrite replaces it, since the
  result is plain text.
- Prompts are English. `systemPrompt` and custom actions can replace them.
