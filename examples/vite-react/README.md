# OpenEdit with Vite and React

`RichTextEditor` with its defaults, saving the document to `localStorage`
after a pause in typing.

```sh
pnpm install && pnpm build      # once, from the repository root
pnpm --filter example-vite-react dev
```

Outside this repository, install the published packages instead:
`npm install @openedit/ui @openedit/react @openedit/core`.
